# 人工质检检查点清单

**版本**: Stage 3 完成后（2026-05-31）  
**目标**: 系统性验证战斗系统实际表现是否符合 DNF 真值  
**角色**: 剑魂（Swordman）  
**怪物**: 哥布林（Goblin）3 种变体

---

## 测试环境准备

### 启动步骤

1. **启动开发服务器**
   ```bash
   npm run dev
   ```
   服务器将在 `http://localhost:5173` 启动

2. **推荐配置**
   - 浏览器: Chrome/Edge 最新版
   - 分辨率: 1920×1080（游戏画布固定尺寸）
   - 禁用浏览器扩展（避免性能干扰）

3. **调试工具快捷键**
   - **F1**: 切换调试覆盖层（显示 actor ID、状态、HP）
   - **F2**: 切换碰撞盒显示（hitbox/hurtbox/pushbox）
   - **F3**: 慢动作模式（0.25× 速度）
   - **F4**: 单帧步进（需先暂停）
   - **F6**: 重置场景
   - **P**: 打印战斗统计到控制台

4. **游戏操作**
   - **方向键**: 移动（左/右）、跳跃（上）
   - **J/K/L**: 普通攻击 1/2/3
   - **F/G/H**: 技能（如果已实现）
   - **空格**: 跳跃
   - **双击方向键**: 冲刺（Dash）

## 1. 基础移动测试

### 1.1 水平移动（Walk）

- [ ] **测试步骤**: 按住左/右方向键，观察角色移动
- [ ] **预期结果**: 
  - 移动速度平滑稳定
  - 速度应为 `143 × (850/1000) = 121.55 px/s`（PVF 真值：moveSpeed=850）
- [ ] **PVF 真值参考**: 
  - `swordman.chr` → `move speed` = 850（%xSPEED_VALUE_DEFAULT）
  - `dnfPhysicsConstants.ts` → `xNormalMoveVelocity` = 143
- [ ] **常见问题**: 
  - 移动速度过快/过慢
  - 移动不流畅（卡顿）
  - 方向切换时有延迟

  - 双击识别失败
